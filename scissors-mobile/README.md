# Scissors Mobile

Expo + React Native starter for the Scissors project.

## Getting started

```bash
cd scissors-mobile
npm install
npm run start
```

## Scripts

- `npm run start`
- `npm run android`
- `npm run ios`
- `npm run web`

## Structure

- `App.tsx` - app shell and background styling
- `src/screens/HomeScreen.tsx` - starter landing screen
- `src/components/*` - reusable UI pieces
- `src/theme.ts` - shared colors and spacing
