# Scissors

Scissors helps you save and review text you capture throughout the day. Keep
useful snippets, notes, links, and other pieces of text in one place and access
them across your devices.

## Features

- Sign in with Google
- Save text clippings to your personal account
- Review your recent clipping history
- Copy saved text back to your clipboard
- Keep clippings synchronized across supported devices
- Receive updates when a new clipping is available
- Use the Windows app from the system tray
- Capture text quickly with Windows keyboard shortcuts

## Available Apps

### Windows

The Windows desktop app provides a convenient way to capture and review text
while you work. It can stay available from the system tray and supports
keyboard shortcuts for quick capture.

### Android and iPhone

The mobile app is designed for browsing and reviewing your clippings on the go.
It supports Google sign-in, account synchronization, and updates when new
clippings arrive.

### Web

The web experience lets you access Scissors from a modern browser without
installing a desktop or mobile app. It uses the same account and clipping list.

The web experience and some mobile actions are still being completed.

## Current Status

Scissors is under active development. The Windows app and online services are
the most complete parts of the application. Mobile and web support are growing
companion experiences, with additional capture and account features still in
progress.

## Supported Platforms

| App | Supported platforms |
| --- | --- |
| Desktop | Windows |
| Mobile | Android and iPhone |
| Web | Modern web browsers |

Your clippings are stored securely with your account so they can be shared
between the supported apps.

## Project Information

Scissors is made up of desktop, mobile, web, and online services that work
together. Each app can be improved and released independently, while your
account and clipping history remain shared.
